## 2. The re-tuned window circuit (lead A15)

Parameters: (a0, a1, 1-b, r) = (1/1842, 1/1474, 1/83, 29/17), all exact rationals. [P] [exact, Lean `s3_params`]:
0 < a0, a1 <= 1/4; 0 <= 1-b-a0-a1 <= 1/2 (stars inside and outside D); r >= 1; r(a0+a1) <= 1-b; (a0+a1)/(1-b) <= 1/2.

### 2.1 The construction (YL Sec. 3.5, three choices freed) [proof]

YL v1 main.tex ll. 525-607; both re-tune referees re-derived each step against the TeX.
- *Choosing D.* A uniform bn-set D leaves exactly a0 n zeros, a1 n ones and (1-b-a0-a1) n stars of the query
  outside with probability C(n/4, a0 n) C(n/4, a1 n) C(n/2, (1-b-a0-a1) n) / C(n, bn); YL's prefix length and union
  bound are unchanged. So |calD| = 2^{E1 n + o(n)} with E1 = h(b) - h(1/4, a0) - h(1/4, a1) - h(1/2, 1-b-a0-a1).
- *Expansion and sign.* The product over A1 of x_i times the product over A0 of (1 - x_i) is a signed sum over
  A1 ⊆ U ⊆ A1 ∪ A0 with sign (-1)^{|U| - a1 n}; so a1 <= mu := |U|/n <= a1 + a0.
- *Covering.* With q(u) := ceil(r u), a uniform q-subset of comp(D) contains a fixed u-set with probability
  C(q, u)/C((1-b) n, u), so a prefix of length n^2 C((1-b)n, u)/C(q, u) misses U with probability <= e^{-n^2}. This
  needs only u <= q <= (1-b) n; (1-b)n is an integer, so ceil(r u) <= (1-b) n follows from r(a0+a1) <= 1-b.
  "Each U belongs to exactly one Q, and Q ⊇ U" never uses q = 2u.
- *Colours.* ceil(r u) is strictly increasing in u for r >= 1, so |Q| determines mu, the sign is constant on a
  colour, and mu <= theta <= q/n.
- *Right degree.* 2^{(b - 1/2 + a0 + a1) n} C(a0 n, (mu - a1) n) C(q - u, theta n - u): exponent
  R = E0 + h(a0, mu - a1) + h((r-1) mu, theta - mu), E0 := b - 1/2 + a0 + a1.
- *Left degree.* YL's Hoeffding chain 4|D||Q|p + 2n^2|Q| + n^2|D| does not depend on q: a uniform D followed by a
  uniform q-subset of its complement is a uniform q-set, and p <= (n+1) 2^{-q} C(q, theta n) for every q. The three
  exponents are E1, A(mu) := h(1-b, mu) - r mu h(1/r), and E1 + A(mu) + h(r mu, theta) - r mu. **The second term
  counts |calQ| >= 1, so its true exponent is max(A(mu), 0)** (X-c); Lemma 2.1 shows A > 0, so max(A, 0) = A.
  YL's two volume inequalities (used only to drop the first two terms) are not needed: we keep the max of all three.
- So the colour profile is L(mu, theta) = max(E1, max(A, 0), E1 + A + h(r mu, theta) - r mu) and R(mu, theta)
  as above, on the polygon Poly = {a1 <= mu <= a1 + a0, mu <= theta <= r mu} (up to the rounding of Sec. 2.2), and
  V(tau) := max over Poly of tau L + (1 - tau) R.
- *Gate-level test.* `check_circuit.py` builds the circuit at n = 8 and 12 (a0 > a1, a1 > a0, q = u + 1, and YL's
  r = 2 control) and multiplies L R out: 0 mismatches, right degrees within the bound, signs uniform per colour,
  and the 'drop' control fails as it must (36 s). [proof by exhaustive computation at those sizes]

### 2.2 Rounding, windows, hole fixing

- **Rounding with rho = q/n [arg] (X-b).** With q = ceil(r u), a colour has mu <= theta <= rho := q/n with
  r mu <= rho <= r mu + 1/n, so the true colour domain is not inside Poly. Parametrise by (mu, rho, theta) on the
  compact set K_delta = {a1 <= mu <= a1 + a0, r mu <= rho <= r mu + delta, mu <= theta <= rho}. The four terms
  E1, h(1-b, mu) - rho h(mu/rho), E1 + that + h(rho, theta) - rho, and E0 + h(a0, mu - a1) + h(rho - mu, theta - mu)
  are continuous on K_delta, hence uniformly continuous, and on delta = 0 they are the Poly terms. So for every
  eps_1 > 0 there is delta > 0 such that for n >= 1/delta every colour's profile is within eps_1 of a point of the
  Poly profile; YL Lemma 3.4's + eps_1 absorbs this. (YL l. 587 uses the same argument for their rounding.)
- **Windows [arg, as YL].** The first covering denominator becomes C(#0, a0 n) C(#1, a1 n) C(n/2, .), a continuous
  change on the window; circuits are built per query type and the window is symmetric under swapping #0 and #1, so
  YL's flip symmetry still applies with a0 != a1. No step uses a0 = a1.
- **Hole fixing [proof given YL's stated facts]:** S2 Lemma 9.1 (inclusion-exclusion), which uses only the
  symmetries of P_{n,1/2}, never of the circuit.

**Lemma 2.1 (A > 0) [proof; exact [Apos]; Lean `s3_Apos`].** For a1 <= mu <= a1 + a0, A(mu) > 0.
*Proof.* h(1-b, mu) = (1-b) h(mu/(1-b)) and a1/(1-b) <= mu/(1-b) <= (a0+a1)/(1-b) <= 1/2, where h increases, so
h(1-b, mu) >= (1-b) h(a1/(1-b)). And r mu h(1/r) <= r (a0+a1) h(1/r). The certified enclosures give
A(mu) >= (1-b) h(83/1474)/83 - (29/17)(1/1842 + 1/1474) h(17/29) >= 1.7279e-3 > 0. ∎

## 3. The algorithm DET3 (lead A22) and its correctness

Constants: pi := 0.24999546; eps := 1e-9; the rational pair (dL', dR') of Prop. 2.3; xi' := 3.6314576e-5.

**DET3(z, tau).**
- Step 0. If n < n0, brute force, where n0 >= max(202, S2's thresholds, the point from which P0 >= x0) (n0 = 274 for Theorem 3'). Otherwise m := 2 floor(pi n/2). Blocks Q_i := coordinates (i-1)m+1..im, i = 1..4;
  Rr := the other n - 4m coordinates.
- Step 1. Sort and dedupe the 2^m sums of each Q_i, keeping the least-mask representative of each sum.
  d(Q) := m - log2 |Sigma(Q)|. P := argmin_i d(Q_i) (least index on ties); Qa, Qb, Qc := the other three in index
  order. Reorder the coordinates as P, Qa, Rr, Qb, Qc. N := |Sigma(P)| = 2^{m - d(P)}.
- Steps 3-6 of S2 with prefix P and **no Step 2**; Step 3(a) scans from P0 := max(N(b+1), x_0). In each layer j,
  with l_j from S2 Lemma 3.5 at (dL', dR'):
  - A'_j := {(a_P, s1, s2) : a_P in {0,1}^m, s1 in Sigma(Qa), s2 in Sigma(B1_j \ Qa)}, key a_P . z_P + s1 + s2,
    row x(a_P);
  - B'_j := {(b_P, t1, t2) : b_P in T_{m,j}, t1 in Sigma(B2_j \ Qc), t2 in Sigma(Qc)}, key
    tau - b_P . z_P - t1 - t2, query y(b_P);
  - Step 4: the prefix histogram over all 2^m vectors a_P (not deduped), convolved with the histograms of the deduped
    sets; the shift minimises w'_j := 2^{e_L} hA'_j + 2^{e_R} hB'_j over the rotations of R_j;
  - Step 5 (meet in the middle): left (half of P) x Sigma(Qa) against (other half) x Sigma(B1_j \ Qa); right
    (ternary half of P) x Sigma(B2_j \ Qc) against (ternary half) x Sigma(Qc), grouped by nonzero count;
  - Step 6: PM on the kept records; recovery by S2 Cor. 2's bisection on the kept lists, then each stored sum is
    replaced by its representative.

*Gotchas, at the steps where they would break.* Rows keep a_P: merging a_P by prefix sum breaks S2 Lemma 5.2 in
individual layers (control dedupP). Only blocks lying wholly on one side may be deduped; a block with coordinates
in both B1_j and B2_j cannot be (control overlap). Hence the fit, Lemma 3.3.

**Relabelling [proof] (D-d).** DET3 on z is S2's Steps 3-6 (modified as above) on z∘sigma, sigma the reordering
P, Qa, Rr, Qb, Qc. c solves z∘sigma iff c∘sigma^{-1} solves z, and every S2 lemma used is stated for an arbitrary
instance whose prefix is its first m <= n/3 coordinates, so each applies verbatim to z∘sigma.

**Lemma 3.1 (soundness) [proof].** If PM reports a positive count in layer j, the recovered vector is a solution.
*Proof.* A counted pair is (a_P, s1, s2), (b_P, t1, t2) with equal keys and x(a_P) matching y(b_P). Take the
representatives u1 (on Qa), u2 (on B1_j \ Qa), v1 (on B2_j \ Qc), v2 (on Qc). Then a := (a_P, u1, u2, 0 on B2_j) is
in A_j and b := (b_P, 0 on B1_j, v1, v2) is in B_j, with the same keys and the same x, y. By S2 Lemmas 3.1(b) and
3.2, a + b is a solution. The supports of u1, u2 (inside B1_j) and of v1, v2 (inside B2_j) are disjoint because
Qa ⊆ B1_j and Qc ⊆ B2_j (Lemma 3.3). ∎

**Lemma 3.2 (completeness) [proof].** If c is a solution and c_P is in T_j, Step 5 keeps a compatible pair with
equal keys in layer j.
*Proof.* As S2 Lemma 5.2: y := (c_{B1_j} . z) mod p is the same whether c's outside part is a vector or the pair of
sums s1 := c_Qa . z_Qa, s2 := c_{B1 \ Qa} . z. Some r in C_j covers (c_P, y), so some a_P at distance j from c_P has
a_P . z_P + s1 + s2 ≡ r. The records (a_P, s1, s2) and (c_P - a_P, t1, t2), with t1, t2 the sums of c on B2_j \ Qc
and on Qc, exist, have the common key a_P . z_P + s1 + s2 (as c . z = tau), are compatible (S2 Lemma 3.2), and
both have residue r. ∎

**Corollary 3.7 (decision and search) [proof].** By S2 Lemma 5.1 every c_P lies in some T_j; Lemmas 3.1, 3.2 and the
exactness of PM (Y1) give the decision. Search: S2 Cor. 2's bisection uses only "count > 0", which the dedupe
preserves (a positive deduped count exists iff a raw one does, by 3.1 and 3.2); Lemma 3.1 assembles the vector.
